# Intelligent Candidate Discovery System

## Problem Statement

Build an AI-powered candidate ranking engine that understands job descriptions and intelligently ranks candidates.

---

## Architecture

Job Description
↓
Sentence Transformer Embeddings
↓
FAISS Vector Search
↓
Hybrid Ranking Engine
↓
Behavioral Signals
↓
Career Signals
↓
Business Rules
↓
Final Candidate Ranking

---

## Technologies

- Python
- Sentence Transformers
- FAISS
- NumPy

---

## Features

- Semantic Search
- Candidate Ranking
- Behavioral Signal Analysis
- Career Signal Analysis
- AI/ML Candidate Discovery
